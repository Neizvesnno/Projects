# OLX Market Parser

Парсер оголошень OLX.ua з аналізом цін. Збирає видачу за запитом і зберігає звіт в Excel, CSV або JSON. Вміє кешувати результати, відстежувати нові оголошення й зниження цін та надсилати зміни в Telegram.

## Встановлення

Потрібен Python 3.10 або новіший.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Без аргументів скрипт працює в інтерактивному режимі й ставить питання по черзі:

```bash
python main.py
```

Через командний рядок:

```bash
python main.py iphone 13 -x "чохол,скло" --city kiev --min-price 8000 --max-price 20000 --seller private -s price -f xlsx csv
```

| Параметр | Що робить |
|---|---|
| `query` | пошуковий запит |
| `-x`, `--exclude` | стоп-слова через кому, оголошення з ними в назві відкидаються |
| `--city` | місто з адреси OLX: `kiev`, `lvov`, `kharkov`, `odessa`, `dnepr`, `zhitomir`… |
| `--min-price`, `--max-price` | діапазон цін, грн (фільтрує сам OLX) |
| `--seller private\|business` | тільки приватні особи або тільки бізнес |
| `--order relevance\|cheap\|expensive\|new` | порядок видачі на OLX |
| `--pages N` | скільки сторінок завантажити (до 25) |
| `-s`, `--sort` | сортування у звіті: `price`, `price-desc`, `condition`, `date`, `city`, `seller` |
| `-f`, `--format` | `xlsx`, `csv`, `json` (можна кілька) |
| `-o`, `--output` | шлях до звіту, за замовчуванням `results.xlsx` |
| `--refresh` | ігнорувати кеш |
| `--track` | відстежувати нові оголошення й зниження цін |
| `--notify` | надсилати зміни в Telegram |
| `--every N` | повторювати перевірку кожні N хвилин |
| `--delay`, `--workers` | пауза між запитами (с) і кількість паралельних завантажень |

Повний список параметрів: `python main.py --help`.

У PyCharm параметри задаються в Run → Edit Configurations → поле Parameters. Якщо поле порожнє, скрипт запуститься в інтерактивному режимі.

Звіти зберігаються в поточну папку запуску (або за шляхом з `-o`). Кеш `cache.json` і база відстеження `olx_tracker.db` лежать поруч зі скриптом.

## Звіт Excel

- **Оголошення.** Таблиця з фільтрами й сортуванням за будь-яким стовпцем: ціна, стан, тип продавця, місто, область, дати, відхилення від медіани, ТОП, доставка, посилання і фото. Під цінами є середня, мінімальна й максимальна ціна. Ці підсумки перераховуються під активні фільтри.
- **Аналіз.** Медіана, квартилі, розбивка за станом, продавцем, містами й областями, графік розподілу цін, активність за датами і 10 найдешевших оголошень.
- **Зміни.** Аркуш з'являється лише з `--track`: нові оголошення і ті, що подешевшали.

## Кеш

Результати зберігаються в `cache.json` на 30 хвилин. Ключ кешу враховує запит і всі фільтри. Стоп-слова застосовуються вже після кешу, тож їх можна міняти без нового завантаження. Неповні завантаження не кешуються. Якщо мережа недоступна, скрипт бере дані зі старого кешу.

## Відстеження й Telegram

```bash
export TELEGRAM_BOT_TOKEN="токен від @BotFather"
export TELEGRAM_CHAT_ID="твій chat id"
python main.py iphone 13 --city kiev --max-price 15000 --notify --every 30
```

- Історія зберігається в `olx_tracker.db` (SQLite).
- Перший запуск лише записує базу. Зміни показуються з другого запуску, щоб не отримати сповіщення про всі оголошення одразу.
- Якщо надіслати повідомлення в Telegram не вдалося, зміни не позначаються як переглянуті і будуть надіслані наступного разу.

Замість `--every` можна запускати скрипт за розкладом через cron:

```
*/30 * * * * cd /шлях/до/OLX_Market_Parser && .venv/bin/python main.py iphone 13 --notify
```

## Обмеження

- OLX віддає не більше 25 сторінок (1 000 оголошень) на запит. Для повної картини звужуй запит фільтрами.
- Дані беруться з JSON, який OLX вбудовує в сторінку. Якщо його немає, парсер переходить на HTML, але частина полів тоді лишиться порожньою.
- Запити йдуть щонайбільше раз на `--delay` секунд, щоб не навантажувати сайт. Тому 25 сторінок завантажуються приблизно за 25–30 секунд.
