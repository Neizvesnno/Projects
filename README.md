# Projects

A collection of my early programming projects (Python & C++).

Most of these were written some time ago while I was learning. My coding style and skills have improved since then, so please treat this repository more as a history of my progress rather than my current best work.

---

## Structure

### Python

| Folder | Description |
|--------|-------------|
| **Book_Market_Parser** | Asynchronous web scraper for Labirint.ru (books). Collects title, author, publisher, prices, discount and availability. Saves results to JSON and CSV. |
| **OLX_Market_Parser** | Scraper for OLX.ua. Collects product name, price and link, exports to Excel. |
| **Prom_Market_Parser** | Scraper for Prom.ua. Collects product data and saves it to Excel. |
| **ALGERoots** | Math training game (squaring numbers). Includes a console version and a full Tkinter GUI with timer, music, SQLite score storage and difficulty levels. |
| **TKITimer** | Simple timer application with GUI. |

### C++

| Folder | Description |
|--------|-------------|
| **!Important Projects C++** | Collection of small C++ programs and solutions to Eolymp problems (calculators, number processing, geometry helpers, etc.). |
